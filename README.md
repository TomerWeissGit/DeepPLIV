This package is a part of my thesis about causality in partially linear settings.
Partially linear settings are a special case of partially-parametric regression models, where the relationship between
the response and the covariances are linear in some covariances and non-linear in others.
The goal of this package is to provide a set of tools to estimate the causal effect of a treatment on the response in
partially linear settings, where the relationship between the treatment and response is assumed linear while any other
relationship in this setting isn't assumed to be linear.
This is a release of the linearity constraint between the instrumental variable and the exposure of interest and between
other covariances to the response, while still estimating a causal coefficient.
The package is based on the paper "Causal Inference in Partially Linear Models with Instrumental Variables" by
Tomer Weiss & Malka Gorfine, 2024.
